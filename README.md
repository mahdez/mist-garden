# สวนในหมอก (Mist Garden)

เกมปลูกผักพิกเซลในโลกที่มีหมอกจากอุกกาบาต ผักบางต้นกลายเป็นมอนสเตอร์ตอนเก็บเกี่ยว ชนะแล้วได้อุปกรณ์ เซ็ตไอเทม และผลปีศาจ

## รันเกม

```bash
node serve.js
```

จากนั้นเปิด http://localhost:8766

## โครงสร้าง

ไม่ต้องติดตั้งหรือ build ไฟล์ JS โหลดตามลำดับใน `index.html` และใช้ตัวแปรร่วมกัน ลำดับจึงมีผล

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าและลำดับการโหลด |
| `css/style.css` | หน้าตาของเกม |
| `js/core.js` | ตัวช่วยพื้นฐานและ canvas |
| `js/audio.js` | เสียงเอฟเฟกต์ |
| `js/data.js` | ค่าสมดุลเกม: ผัก ไอเทม ผลปีศาจ มอนสเตอร์ แผนที่ |
| `js/crops-more.js` | ผัก 6 ชนิดที่เพิ่มภายหลัง พร้อมมอนสเตอร์ อุปกรณ์ และผลปีศาจ |
| `js/state.js` | สถานะเกม เซฟ และค่าพลัง |
| `js/art.js` | ภาพพิกเซล |
| `js/ui.js` | แผงสถานะและเมนู |
| `js/farm.js` | ปลูก เก็บเกี่ยว ร้านค้า และเมนูในฟาร์ม |
| `js/battle.js` | ระบบต่อสู้และของดรอป |
| `js/title.js` | หน้าแรกและการเริ่มเกม |
| `js/render.js` | การวาดจอและการเดิน |
| `js/input.js` | คีย์บอร์ด เมาส์ และปุ่มบนจอ |
| `js/main.js` | เริ่มเกม |
